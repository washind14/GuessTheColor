# 🎨 Guess The Color

![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)

## 📌 Overview
Guess The Color is a fun and interactive frontend web game where users test their knowledge of colors by guessing the correct RGB value. Built with HTML, CSS, and JavaScript, this project provides an engaging way to learn and practice color recognition.

## ✨ Features
- 🎯 Randomly generated RGB color challenges
- 🎨 Simple and responsive UI for a smooth experience
- 🌙 Dark mode support for comfortable gameplay

## 🛠️ Technologies Used
- **HTML5**: Structuring the game elements
- **CSS3**: Styling the user interface
- **JavaScript (Vanilla JS)**: Handling game logic and interactivity

## 🚀 Getting Started
### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)
- Basic understanding of JavaScript (optional for customization)

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/washind14/GuessTheColor.git
   ```
2. Navigate to the project directory:
   ```sh
   cd GuessTheColor
   ```
3. Open the `index.html` file in your browser to start playing!

## 🏗️ Project Structure
```
GuessTheColor/
```
